SKILLSETRA — QUICK START

1. Extract the complete ZIP into a writable folder.
2. Install Node.js 20+ and Python 3.10+ if needed.
3. Double-click START_TEST_NO_SIGN.bat for the local demo, or START_FULLSTACK.bat for full-stack mode.
4. Wait for readiness checks and open http://localhost:3000.
5. To stop manually, use the matching STOP_TEST_NO_SIGN.bat or STOP_FULLSTACK.bat.

First launch downloads dependencies. A deprecation warning by itself is not proof of failure; check the reported npm exit code and service readiness. See DEPLOYMENT_GUIDE.md for troubleshooting.

For separate Vercel frontend + Render backend + Supabase Auth/database deployment, read VERCEL_SUPABASE_DEPLOYMENT_GUIDE.md.
