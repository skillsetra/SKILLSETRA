# Hackathon demo script

1. Open landing page and show the competency map animation.
2. Create/sign in to demo account.
3. Choose ML Engineer in onboarding.
4. Open Dashboard and point out Strong / Developing / Limited / Transfer Gap.
5. Run the unknown challenge.
6. Submit a reasoning response and show the evidence diagnosis.
7. Open Learn and ask the AI Coach for a targeted explanation.
8. Analyze the sample project and complete the integration-test upgrade.
9. Open Assessment and clear or retry the baseline.
10. Open Career to inspect role evidence and illustrative salary bands.
11. Open Roadmap to show the role-specific path.
12. Open GitHub and explicitly select a demo repository.
